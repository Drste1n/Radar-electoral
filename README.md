# Radar Electoral



\# Radar Electoral



Radar Electoral es un proyecto en \*\*Java (Spring Boot)\*\* que busca crear una página web con información pública y transparente sobre los candidatos presidenciales de Brasil en las elecciones de 2026.



\## 🎯 Objetivos del proyecto

\- Mostrar datos relevantes que interesan a la ciudadanía:

&#x20; - 📜 Leyes que aprobaron o impulsaron

&#x20; - 💰 Gastos de campaña y financiamiento

&#x20; - 🏛️ Partidos políticos y alianzas

&#x20; - 📊 Información pública disponible en portales oficiales

\- Facilitar la comparación entre candidatos de forma clara y simple.

\- Aprender desarrollo web en Java y trabajo colaborativo con GitHub.



\## 📂 Estructura inicial

\- \*\*Backend (Java + Spring Boot):\*\* lógica de negocio y APIs.

\- \*\*Frontend (HTML/CSS/JavaScript):\*\* interfaz para mostrar la información.

\- \*\*Base de datos (MySQL/PostgreSQL):\*\* almacenamiento de datos públicos.
